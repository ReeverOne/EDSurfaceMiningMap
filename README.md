# EDSurfaceMiningMap
This allows anyone to map a surface mining spot in Elite Dangerous for the new Rhino. Once you have started to populate the data, you can select the system > planet > mining spot and it will display a map of the deposits you have recorded. You can then filter by deposit type and size (number of rigs you can put down). Hovering over a deposit will show you the deposit type, size (number of rigs) and lat/long (if you input that information). Clicking on the deposit will copy the lat/long (if available) to your clipboard to easily enter the information into a third-party system to navigate directly to the deposit.
## Prerequisites (venv)
Install (via pip install):
* customtkinter
* matplotlib
* pandas
